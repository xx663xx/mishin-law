# «Подкинули»

## Локальный запуск

Для сайта с приемом обращений нужен Node.js 22 или новее.

```sh
node server.mjs
```

По умолчанию сайт доступен по адресу `http://127.0.0.1:8080`. Готовые обращения записываются в `~/.podkinuli/inquiries` с правами доступа только для пользователя, от имени которого запущен сервер. Каждое обращение хранится в отдельном JSON-файле. Сотрудник с доступом к каталогу может найти запись по полю `reference`, которое показывается посетителю после отправки.

`HOST`, `PORT` и `INQUIRIES_DIR` задаются через переменные окружения. Каталог обращений должен находиться вне каталога сайта. Для рабочего размещения серверу нужны HTTPS через обратный прокси и постоянное хранилище для этого каталога. Прокси должен сохранять заголовок `Host`. Почтовые уведомления и CRM не подключены.

При статическом размещении работают досье, подбор, профили и шаблоны. Для приема заявок нужен серверный маршрут `POST /api/inquiries`.

Основное досье и карточки в профилях показывают иллюстративные сценарии.
